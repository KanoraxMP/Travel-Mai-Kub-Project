# TravelMaiKub — บันทึกการท่องเที่ยวของฉัน

แอปพลิเคชันบันทึกการท่องเที่ยว พัฒนาด้วย Flutter และ Dart เพื่อให้ผู้ใช้สามารถจัดการข้อมูลสถานที่ท่องเที่ยวและดูข้อมูลจากบริการ API ได้

## คุณสมบัติของแอป
- ระบบเข้าสู่ระบบด้วย Firebase Authentication
- เพิ่ม แก้ไข ดูรายละเอียด และลบข้อมูลสถานที่ท่องเที่ยว
- จัดเก็บข้อมูลสถานที่ท่องเที่ยวด้วย Cloud Firestore
- แสดงและจัดการข้อมูลที่จัดเก็บใน SQLite
- ดึงข้อมูลจาก API เช่น สภาพอากาศและข้อมูลประเทศ
- แสดงข้อมูลผ่านหน้ารายการ หน้ารายละเอียด และหน้าเกี่ยวกับแอป

## เทคโนโลยีที่ใช้
- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- SQLite
- REST API

## วิธีติดตั้งแอป
1. นำไฟล์ `app-release.apk` ไปยังโทรศัพท์ Android
2. เปิดไฟล์ APK และอนุญาตการติดตั้งจากแหล่งที่มานั้น หากระบบร้องขอ
3. ติดตั้งและเปิดแอป TravelMaiKub
4. เข้าสู่ระบบด้วยบัญชีที่ลงทะเบียนไว้

## วิธีใช้งานเบื้องต้น
1. เข้าสู่ระบบเพื่อเปิดหน้าหลักของแอป
2. เลือกหน้ารายการเพื่อดูและจัดการสถานที่ท่องเที่ยว
3. เพิ่ม แก้ไข หรือลบรายการได้ตามต้องการ
4. เลือกหน้า SQLite เพื่อดูข้อมูลที่จัดเก็บในฐานข้อมูล SQLite
5. เลือกหน้าออนไลน์เพื่อดูข้อมูลจาก API
6. เลือกหน้าเกี่ยวกับเพื่อดูข้อมูลของแอป

## ไฟล์สำหรับติดตั้ง
- ไฟล์ APK สำหรับ Android อยู่ที่:

- `build/app/outputs/flutter-apk/app-release.apk`

## หมายเหตุ
- แอปต้องเชื่อมต่ออินเทอร์เน็ตสำหรับการเข้าสู่ระบบ Firebase การเข้าถึงข้อมูลออนไลน์ และการใช้งานฟังก์ชันที่ต้องอาศัยบริการภายนอก
